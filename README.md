# 사이트 분석 시스템 (브이월드 + 건축물대장 → DXF)

**주소를 넣거나 지도에서 영역을 끌면** 그 대상지의 국가공간정보와 건축물대장을
**PNU로 조인**해서, Rhino·AutoCAD에서 바로 여는 DXF를 만듭니다.
전국 어느 지번이든 같은 절차로 돕니다. **특정 프로젝트에 종속된 판정 로직은 넣지 않습니다** —
어떤 기준으로 부지를 고를지는 필터로 그때그때 정합니다.

```
"서울 동대문구 제기동 988"  또는  지도에서 드래그한 영역
        │
        ├─ 지적도(V-World)   parcel.pnu ─┐
        ├─ 건물(V-World)   building.pnu ─┼─ PNU 19자리 조인 ─→ out/<대상지>/
        └─ 건축물대장         ledger.pnu ─┘        site.sqlite · DXF
```

## 0. 준비 — 인증키 2개

### ① 브이월드 (지적도·건물·도로·용도지역·지오코딩)

1. <https://www.vworld.kr> 회원가입 / 로그인
2. **오픈API → 인증키 → 인증키 발급신청**
   (메인의 "추천API" 카드는 레퍼런스 문서 바로가기지 발급 버튼이 아닙니다)
3. **활용API는 중복 선택 가능**하고 키 하나로 전부 씁니다. 체크할 것:

   | 항목 | | 이유 |
   |---|:---:|---|
   | 데이터 API (2D) | ✅ | 지적도·건물·도로 — 핵심 |
   | 검색 API | ✅ | 주소 → 좌표 지오코딩 |
   | 2D지도 API 2.0 | ✅ | 배경 항공사진 타일 |
   | 웹지엘 3D지도 API | ❌ | 브라우저 3D 뷰어용. DXF 작업엔 무관 |

4. 사이트 URL은 `http://localhost`

> **주의** — 브이월드 키는 신청서에 적은 URL에 묶여 있습니다. `.env`의 `VWORLD_DOMAIN`이
> 신청서의 사이트 URL과 **정확히 같아야** 합니다. `INVALID_KEY`가 뜨면 대개 이 값 문제입니다.

### ② 공공데이터포털 (건축물대장 — 구조·용도·사용승인일)

1. <https://www.data.go.kr> 회원가입 / 로그인
2. **[건축HUB 건축물대장정보 서비스](https://www.data.go.kr/data/15134735/openapi.do)** → 활용신청
   (자동승인. 개발계정 트래픽 하루 1,000건)
3. 마이페이지에서 키 확인 → **일반 인증키(Decoding)** 쪽을 복사

### ③ .env 작성

`.env.example`을 `.env`로 복사하고 사용하는 API 키를 붙여넣으세요.

3D 내보내기의 **나노바나나** 사진 렌더링을 쓰려면
[Google AI Studio API Keys](https://aistudio.google.com/apikey)에서 Gemini API 키를 만든 뒤
`GEMINI_API_KEY`에 넣으세요. 기본 모델은 Nano Banana 2인
`gemini-3.1-flash-image`이며, `GEMINI_IMAGE_MODEL=gemini-3-pro-image`로 바꾸면
더 높은 품질의 Nano Banana Pro를 사용할 수 있습니다. 이 키는 서버에서만 읽고
브라우저 화면으로 내려보내지 않습니다.

> **화면에서 넣어도 됩니다.** 왼쪽 위 「내 인증키」에 붙여넣으면 그 브라우저에만 저장되고,
> 요청마다 실려 갑니다. **화면에서 넣은 키가 서버의 `.env`를 이깁니다.**
> 여러 사람이 한 서버를 같이 쓸 때 각자 자기 키로 자기 한도를 쓰라는 뜻입니다.
> 서버는 남의 키를 저장하지 않습니다.

### ④ 친구에게 열어 주기 (선택)

```powershell
python share.py
```

인터넷 주소와 암호를 만들어 줍니다. 친구는 **아무것도 깔지 않고** 브라우저로 들어와
분석·다운로드·다이어그램을 그대로 씁니다. 내 컴퓨터가 일하는 것이기 때문입니다.

- `cloudflared` 가 필요합니다: `winget install --id Cloudflare.cloudflared`
- **이 창을 닫으면 주소가 죽습니다.** 내 컴퓨터가 켜져 있어야 합니다.
- 암호를 거는 이유 — 분석은 하루 1,000건 한도를 태우고 삭제는 되돌릴 수 없습니다.
- 친구가 「내 인증키」에 자기 키를 넣으면 **내 한도가 아니라 친구 한도**를 씁니다.

필요한 파이썬 패키지 (이미 설치되어 있음): `requests pyproj shapely ezdxf matplotlib`

## 1. 사용법 — 웹 뷰어

바탕화면의 **「사이트 분석」** 바로가기를 더블클릭하면 서버가 뜨고 브라우저가 자동으로 열립니다.
(같은 폴더의 `run.bat` 을 눌러도 됩니다.)

> **`run.bat` 은 ASCII만 사용합니다 — 한글을 넣지 마세요.**
> cmd.exe 는 배치파일을 시스템 코드페이지(한국어 Windows = CP949)로 읽기 때문에,
> UTF-8 한글이 들어가면 바이트가 깨져 파서가 엉키고 `'se'은(는) 내부 또는 외부 명령...` 같은
> 오류가 납니다. 파일명도 같은 이유로 ASCII로 둡니다.
> 한글 안내 문구는 인코딩을 제어할 수 있는 `web.py` 쪽에서 출력합니다.

- 이미 켜져 있는데 또 누르면 서버를 중복으로 띄우지 않고 **브라우저만** 엽니다.
- 종료는 검은 창에서 **Ctrl+C**, 또는 창을 닫으면 됩니다.
- 창을 닫으면 서버도 같이 꺼집니다. 분석 결과는 `out/` 에 남아 있으니 다시 켜면 그대로 있습니다.

터미널에서 직접 띄우려면:

```powershell
cd "$env:USERPROFILE\Desktop\vworld-sitemap"
python web.py
```

→ **http://127.0.0.1:8000** (포트를 바꾸려면 `set PORT=8080` 후 실행)

| 하는 일 | 방법 |
|---|---|
| 대상지 분석 | 주소를 넣거나, 「지도 영역으로」 탭에서 범위를 드래그 |
| 필지 정보 보기 | 필지 클릭 → 지목·대지면적·주용도·구조·사용승인일·건폐율·용적률 |
| 조건으로 걸러내기 | 필터 패널 (지목·구조·주용도·면적·연도·건물구성) — 조건은 누적(AND) |
| 부지 고르기 | 필지 클릭, 「영역 드래그 선택」, 또는 「필터 결과 전체 선택」 |
| 내보내기 | 「선택 부지만 DXF 받기」 또는 「전체 DXF」 |
| 지형 받기 | 「지형 DXF」 · 「표고점 CSV」 — 분석할 때 같이 만들어집니다 |
| 대상지 지우기 | 대상지 목록 옆 「삭제」 |

「분석 시작」을 누르면 ①수집 → ②조인 → ③도면 → **④지형**까지 돕니다.
서울 밖이라 지형이 없으면 그 자리에 안내가 뜨고, 예전에 분석해 둔 대상지는
「지형 가져오기」로 나중에 붙일 수 있습니다.

### 다이어그램 탭

왼쪽 위 **「다이어그램」** 탭으로 넘어가면 같은 대상지가 **축측 3D**로 섭니다.
CAD를 열지 않고 매스와 지형을 확인하는 자리입니다.

| | |
|---|---|
| 조작 | 끌어서 회전 · 휠 확대 · Shift+끌기 이동 |
| 시점 | 「아이소 / 배치 / 입면」 프리셋, 앙각 슬라이더 |
| 매스 | 층고(2.4~5m) · 지형 수직 과장(×1~6) · 반경(150~600m) |
| 표시 | 건물 매스 · 필지 · 지형면 · 등고선 · 면 음영 · 층수 표기 · 흰 바탕 |
| 내보내기 | PNG·SVG·AI 레이어 ZIP·GLB·Rhino 3DM |

- 좌표계와 원점을 **DXF와 똑같이** 씁니다. 화면에서 본 것과 CAD로 뽑은 것이 어긋나지 않습니다.
- **GLB**는 형식 특성상 메시입니다. 대신 건물마다 바닥·벽·지붕을 한 닫힌 메시 객체로
  내보내고, 지형은 표고가 반영된 삼각망으로 내보냅니다.
- Rhino에서 면을 바로 편집하려면 **3DM**을 고르세요. 건물은 면 방향을 바깥으로
  통일한 객체별 닫힌 Brep이고, 대지는 화면의 「대지 콘타 두께」를 적용한 닫힌
  폴리서피스입니다. 부드러운 기준 NURBS 윗면도 숨김 레이어에 함께 들어갑니다.
- 「사이트 분석」에서 고른 부지는 다이어그램에서도 **붉게** 표시됩니다.
- **높이는 층수 × 층고로 추정한 매스입니다.** 실측 높이가 아닙니다. 대장에 층수가 없는
  건물은 1층으로 세웁니다 (제기동 1,087동 중 1,014동은 층수가 확인됩니다).
- 지형면은 표고점을 거리 역수 가중(IDW)으로 보간한 격자입니다. 삼각망이 아닙니다.
  평지에서는 기복이 안 보이니 「지형 수직 과장」을 올려 보세요.
- 외부 3D 라이브러리를 쓰지 않고 캔버스에 직접 그립니다. 인터넷 없이 돌고,
  제기동 기준 8,613면을 **13.7ms/프레임**에 그립니다.

배경지도는 브이월드 일반지도/항공사진 전환 가능. 필지·건물·수집범위는 각각 껐다 켤 수 있습니다.

#### 2D 도로면 — VWorld 지역 Polygon

2D 도판의 `도로면 · VWorld Polygon`은 연속지적도의 `지목=도` 필지를 사용하지 않습니다.
우선 `(도로명주소)실폭도로`(dsId=30057), 다음으로 `연속수치지형도 도로경계_면`
(dsId=30179)의 지역별 SHP를 로컬에 버전별로 보존하고, 대상지 BBOX와 spatial clip한
Polygon을 씁니다. 새 판은 검증과 GeoPackage 변환을 마친 뒤에만 `current.json`이 가리키며
기존 판은 삭제하지 않습니다.

VWorld 자료실 로그인이 필요한 환경에서 자동 다운로드가 막히면 NGII 연속수치지형도
도로중심선 `lt_l_n3a0020000`의 실제 폭(`rvwd`)을 buffer한 면을 fallback으로 씁니다.
이 경우 화면 왼쪽 위 출처에도 fallback이라고 표시됩니다. 기존 `LT_L_SPRD`는 도로명
중심선 보조 레이어로만 남고 기본값은 꺼짐입니다.

브라우저에서 공식 지역 ZIP을 받은 경우 한 번만 설치하면 됩니다:

```powershell
python road_data.py import "C:\Downloads\(도로명주소)실폭도로_서울.zip"
python road_data.py build --all
python road_data.py status
```

## 2. 사용법 — 커맨드라인

```powershell
python site.py "서울특별시 동대문구 제기동 988"
```

이 한 줄이 ①수집 → ②조인 → ③도면화를 전부 돕니다. 다른 지역도 주소만 바꾸면 됩니다:

```powershell
python site.py "부산광역시 중구 동광동3가 1" --radius 250 --name 부산원도심
python site.py "전주시 완산구 교동 105"      --radius 400
python site.py --list                        # 지금까지 분석한 대상지 목록
```

| 옵션 | 뜻 |
|---|---|
| `--radius` | 중심에서의 반경(m). 기본 350 |
| `--name` | 폴더명. 생략하면 지오코딩된 주소로 자동 |
| `--no-ledger` | 건축물대장 조회 생략 (data.go.kr 키 없을 때) |
| `--skip-fetch` | 이미 받아둔 데이터로 도면만 다시 생성 |
| `--select` | 선택 필지 PNU 지정 |

결과는 **대상지별로 따로** 쌓입니다:

```
out/
  제기동/
    제기동_사이트맵.dxf     ← CAD로 열기
    site.sqlite             ← 조인된 DB (SQL로 직접 질의)
    좌표기준.txt            ← DXF 원점의 실좌표 (반드시 보관)
    미리보기.png
    geojson/                ← 원본 데이터 (QGIS·재변환용)
  부산원도심/
    ...
```

단계별로 따로 돌릴 수도 있습니다:

```powershell
python fetch_site.py "제기동 988" --name 제기동   # ①
python build_db.py --name 제기동                  # ②
python to_dxf.py  --name 제기동 --preview         # ③
python terrain.py --name 제기동                   # ④ 지형 (선택)
```

`--name`을 생략하면 **가장 최근에 작업한 대상지**를 이어받습니다.

### ④ 지형 — 전국 NGII DEM · 서울 등고선/표고점

```powershell
python site.py "서울 동대문구 제기동 988" --terrain    # 한 번에
python terrain.py --name 제기동                        # 따로
python terrain.py --name 제기동 --flat                 # Z를 0으로 (2D 도면용)
python terrain_data.py import "C:\Downloads\공개DEM.zip" # 서울 밖 NGII DEM 한 번 설치
python terrain_data.py status                           # 설치 도엽·버전 확인
```

**브이월드에는 등고선·DEM이 없습니다.** 2D 데이터 API 레이어 목록에 지형 계열이 없고,
표고 격자를 주던 3D 데이터 Open API는 2019년에 폐쇄됐습니다(공간정보 보안관리규정).

전국은 국토정보플랫폼에서 받은 **국토지리정보원 공개 DEM** ZIP·IMG·GeoTIFF를
`terrain_data.py import` 또는 사이트 분석의 `NGII DEM 설치` 버튼으로 한 번 설치합니다.
파일의 실제 좌표계와 WGS84 범위를 검사해 `cache/terrain/versions/`에 버전별로 보존하고,
새 대상지는 BBOX와 겹치는 현재 도엽을 자동으로 선택합니다. 기존 버전은 삭제하지 않습니다.

설치된 전국 DEM이 대상지를 덮지 않을 때 서울 안에서는 **서울 열린데이터광장 「서울시
경사도」**(OA-22241)를 fallback으로 씁니다. 국토지리정보원 2023년 기준 수치지형도
1:5000에서 뽑은 등고선·표고점 SHP이며, 44MB 서울 전역 파일을
`cache/seoul_terrain/`에 한 번만 받아둡니다. 다시 받으려면 `--refresh`.

원자료는 EPSG:5174라 대상지 좌표계로 변환하고, **사이트맵과 같은 원점**을 씁니다.
공공누리 1유형(출처표시)이며 출처는 `지형_출처.txt`에 남습니다.

| 알아둘 것 | |
|---|---|
| **서울 밖 DEM** | 국토정보플랫폼 map.ngii.go.kr에서 해당 영역의 공개 DEM을 받아 설치하세요. 포털 로그인 다운로드라 자동 수집하지 않습니다 |
| **도엽 자동 선택** | 설치 후에는 주소마다 다시 지정하지 않습니다. 대상지 BBOX와 겹치는 현재 버전 도엽을 자동으로 사용합니다 |
| **평지에는 등고선이 없습니다** | 주곡선이 5m 간격이라 제기동 700m 범위에 등고선이 **1개**뿐입니다 (표고 15m). 대신 **표고점 31개**로 13.5~16.9m, 고저차 3.4m가 읽힙니다 |
| 경사지는 잘 나옵니다 | 북촌 같은 곳은 등고선 15개·표고점 25개, 고저차 43.7m |
| **대지 레벨용이 아닙니다** | 1:5000 도면입니다. 실제 대지 레벨은 현황측량 성과를 따르세요 |

### 좌표계는 자동으로 잡힙니다

대상지 경도에 맞는 국가 표준 TM 원점을 고릅니다.
서부 `5185` / 중부 `5186` / 동부 `5187` / 동해 `5188`.
고정하려면 `config.json`의 `target_crs`에 `"EPSG:5186"`처럼 직접 적으세요.

### 부지 확정 후

`site.sqlite` 의 `parcel_full` 에서 쓸 필지의 `pnu` 값을 골라서:

```powershell
python to_dxf.py --name 제기동 --select 1123010300109880000 --preview
```

선택한 필지의 **지적선만** `V-SITE` 레이어(빨강)로 분리되고, 합계 면적이 출력됩니다.
그 위의 건물은 원래 레이어에 남으므로 도면 작업에 그대로 씁니다.

## 2. DXF 레이어 구성

범위를 세 단계로 나눠 씁니다.

| | 이름 | 뜻 |
|---|---|---|
| 01 | **CONTEXT** | 광역 분석 범위. 도로망·주변 건물·도시조직을 보는 넓은 범위 |
| 02 | **PROJECT SITE** | 공모가 지정한 대상지. 법정동 전체이거나 지도에서 그린 경계 |
| 03 | **DESIGN AREA** | 그 안에서 실제로 개입할 영역. 필지를 골라 지정 |


| 레이어 | 내용 | 출처 |
|---|---|---|
| `V-PARCEL` / `V-PARCEL-TXT` | 지적선 / 지번 | `LP_PA_CBND_BUBUN` |
| `V-BLDG` / `V-BLDG-TXT` | 건물 외곽선 / `층수 승인연도 구조` | `LT_C_SPBD` + 대장 |
| `V-ROAD` | 도로명주소 도로 | `LT_L_SPRD` |
| `V-ZONE` / `V-ZONE-TXT` | 용도지역(도시지역) | `LT_C_UQ111` |
| `V-DISTRICT` / `V-DISTRICT-TXT` | 지구단위계획구역 | `LT_C_UPISUQ161` |
| `V-PLANROAD` / `V-PLANROAD-TXT` | 도시계획도로 (대로·중로·소로) | `LT_C_UPISUQ151` |
| `V-CONTEXT` | **01** 광역 분석 범위 — 실제 요청한 수집 범위 | — |
| `V-PROJECT-SITE` | **02** 공모 대상지 경계 — 자르기 기준 (법정동 또는 그린 경계) | — |
| `V-DESIGN-AREA` | **03** 설계 범위 — `--select` 로 지정한 필지의 지적선 | — |

지형은 별도 파일 `<대상지>_지형.dxf` 로 나옵니다 (아래 4장). 원점이 같아 0,0에 넣으면 겹칩니다.

| 레이어 | 내용 |
|---|---|
| `V-CONTOUR` / `V-CONTOUR-MAJOR` | 주곡선 5m / 계곡선 25m — 표고값이 Z에 들어간 3D 폴리라인 |
| `V-CONTOUR-TXT` | 등고수치 |
| `V-SPOT` / `V-SPOT-TXT` | 표고점 / 표고값 |

- 좌표계는 **자동 선택**(위 참고), 단위 **meter**
- 수집범위 중심이 도면 원점(0,0)에 오도록 평행이동합니다.
  실좌표가 필요하면 `--origin absolute`, 되돌릴 값은 `좌표기준.txt`에 있습니다.
- **대상지 경계로 모든 객체를 잘라냅니다.** 지도에서 점으로 그린 경계가 있으면 그것을,
  없으면 수집범위 사각형을 씁니다. 잘린 자리가 경계선에 물려 **닫힌 도형**이 되므로
  CAD에서 바로 면으로 씁니다 (제기동 기준 필지·건물 폴리라인 4,631개 전부 닫힘).
  자르지 않고 통째로 받으려면 `to_dxf.py --no-crop`, 또는 `config.json` 의
  `crop_to_boundary: false`.
- 면적·지목 같은 **속성값은 자르기 전 도형**에서 나옵니다. 잘려도 필지 면적은 실제 값입니다.

## 3. DB 직접 질의

`out/<대상지>/site.sqlite`에 테이블 `parcel` / `building` / `ledger`와
뷰 `parcel_full`이 있습니다. 웹 필터로 안 되는 조건은 SQL로 직접 씁니다.

```sql
-- 조건에 맞는 필지 (예: 목구조 + 1960년대 + 100~600m²)
SELECT jibun, 필지면적_m2, tot_area, strct, roof, use_apr_year
FROM parcel_full
WHERE strct LIKE '%목%' AND use_apr_year BETWEEN 1960 AND 1969
  AND jimok = '대' AND 필지면적_m2 BETWEEN 100 AND 600
ORDER BY 필지면적_m2 DESC;

-- 한 지번 위에 여러 채가 얹힌 필지 (집합적 계획 후보)
SELECT jibun, 필지면적_m2, 건물동수, 대장건수 FROM parcel_full
WHERE 대장건수 >= 5 ORDER BY 대장건수 DESC;

-- 같은 본번끼리 묶어 보기 (인접 필지 통합 검토)
SELECT substr(pnu,11,4) AS 본번, COUNT(*) AS 필지수, ROUND(SUM(필지면적_m2)) AS 합계면적
FROM parcel_full WHERE jimok = '대' GROUP BY 본번 HAVING 필지수 >= 3
ORDER BY 합계면적 DESC;

-- 대장에 없는 건물이 있는 필지 (무허가·미신고 확인 필요)
SELECT jibun, 건물동수, 대장건수 FROM parcel_full WHERE 건물동수 > 대장건수;

-- 나대지 (건물도 대장도 없는 대지)
SELECT jibun, 필지면적_m2 FROM parcel_full
WHERE jimok = '대' AND 건물동수 = 0 AND 대장건수 = 0 ORDER BY 필지면적_m2 DESC;
```

`build_db.py`를 돌리면 지목·구조·주용도·사용승인 연대 분포가 함께 출력됩니다.
어떤 조건으로 걸러야 할지 잡는 출발점으로 쓰세요.

## 3.5 자료가 어디서 오고 언제 다시 받는가

```powershell
python status.py              # 지금 뭐가 있고 뭐가 없는지
python status.py --name 제기동
```

네 층으로 나뉩니다. **위로 갈수록 비싸고 아래로 갈수록 공짜입니다.**

### ① 한 번만 받으면 되는 것 — 대상지가 몇 개든 한 벌

| | |
|---|---|
| 서울 수치지형도 (등고선 8,570 · 표고점 45,870) | `cache/seoul_terrain/` · **75MB** |
| 출처 | 서울 열린데이터광장 「서울시 경사도」 (OA-22241) |
| 인증키 | **필요 없음** |
| 다시 받기 | `python terrain.py --refresh` |

### ② 대상지마다 한 번 — 받고 나면 다시 안 받음

| | 어디서 | 캐시 위치 | 비고 |
|---|---|---|---|
| 지적도·건물·도로·용도지역 | 브이월드 | `out/<대상지>/geojson/*.geojson` | 키 필요 |
| 건축물대장 | 공공데이터포털 | `out/<대상지>/geojson/_ledger_*.json` | **법정동 단위** — 이웃 대상지끼리 서로 얻어 씀 |
| 위성사진·일반지도 | 브이월드 타일 | `out/<대상지>/바탕_*.png` | 반경·크기·흑백 조합마다 한 장 |

건축물대장은 **하루 1,000건** 한도가 있는 유일한 자료입니다. 그래서 법정동 단위로 캐시합니다.
`--refresh-ledger` 를 주지 않는 한 다시 부르지 않습니다.

### ③ 매번 계산 — 바깥을 안 부름, 있는 파일로만

도면(DXF) · 장면(2D/3D 다이어그램) · PNG/SVG.

장면은 투영과 지형 보간에 1~2초가 걸려서 `out/<대상지>/_scene_*.json` 에 캐시합니다.
**원본 파일이 바뀌면 자동으로 다시 만듭니다** — 원본들의 수정 시각·크기를 지문으로 씁니다.
제기동 기준 1.78초 → 0.23초.

### ④ 늘 실시간 — 캐시하지 않음

| | |
|---|---|
| 배경지도 타일 | 지도를 움직일 때마다. **브라우저가 직접** 브이월드를 부릅니다 |
| 주소 ↔ 좌표 (지오코딩) | 분석을 시작할 때 한 번 |

## 4. 알아둘 한계

- 연속지적도는 **지적 경계**이지 측량 성과가 아닙니다. 실제 경계와 오차가 있습니다.
  공모전·발주처가 지적 CAD를 따로 제공한다면 **경계는 그 파일이 기준**이고,
  이 도구는 그 바깥의 도시 맥락을 채우는 용도로 쓰세요.
- 건축물대장은 **법정동 전체**를 받습니다. 수집 범위 밖 필지가 섞이는 건 정상이고,
  `build_db.py`가 조인률을 출력합니다.
- 대장은 **미등재 건물이 있습니다.** 무허가·미신고 건물은 대장에 없으므로
  `건물동수 > 대장건수`인 필지는 따로 확인이 필요합니다.
- **한 지번 위에 여러 채가 얹힌 집합 필지가 흔합니다.** (예: 동대문구 제기동 341번지 —
  대지 11,878m²에 대장 28건) 대지면적만 보고 고르면 안 되고 `대장건수`를 같이 봐야 합니다.
- 대장은 **법정동 단위로 받아 캐시**합니다(`out/<대상지>/geojson/_ledger_*.json`).
  개발계정 트래픽이 하루 1,000건이라 재실행 때는 캐시를 씁니다.
  최신으로 다시 받으려면 `--refresh-ledger`.
- **건물이 필지 경계를 넘는 것은 정상입니다.** 두 레이어는 서로 정합되어 있고
  (제기동 2,080쌍 측정: 최적 평행이동 0.25m = 계통 편차 없음, 겹침 중앙값 96.2%),
  오래된 도심에서는 건물이 실제로 여러 필지에 걸쳐 있습니다.
  제기동은 **37.4%(804동)가 2필지 이상**에 걸쳐 있고, 158동은 등록 PNU와 실제 위치 필지가 다릅니다.
  그래서 `--only-selected`는 건물을 **PNU가 아니라 도형이 겹치는지로** 고릅니다.
  (PNU로 고르면 부지 위 건물이 빠지고 엉뚱한 게 딸려옵니다.)
- `LT_C_SPBD`(도로명주소 건물)와 대장은 각각 다른 체계라 동 단위로 1:1이 아닙니다.
  이 도구는 **필지(PNU) 단위**로 붙이고, 한 필지에 여러 동이면 **주건축물 중 연면적이 가장 큰
  동**을 대표로 씁니다 (`parcel_full` 뷰). 나머지 동은 `ledger` 테이블에 그대로 있습니다.

### 다이어그램의 VWorld 실물 3D

3D 다이어그램의 **뷰 → VWorld 실물**을 누르면 그때 처음 WebGL 3D 지도를 받습니다.
기존 다이어그램은 PNG·SVG·GLB·3DM 내보내기의 기준으로 계속 남고, 실물 보기는 교량·
고가도로·주변 건물의 실제 컨텍스트를 확인하는 용도입니다. DESIGN AREA 윤곽을 겹쳐
볼 수 있고, 충돌하는 VWorld 건물은 **건물 숨기기**로 직접 눌러 가릴 수 있습니다.

VWorld 신청 화면에서 같은 키에 **3D 지도 API와 WMS/WFS API**가 허용되어 있어야 합니다.
키는 화면에 저장한 개인 키를 우선하고, 없으면 서버 `.env`의 `VWORLD_KEY`를 사용합니다.

### 도로 데이터 계층

- 기본 형상: 지역별 실폭도로(dsId 30057), 없으면 도로경계_면(dsId 30179)
- 분석값: NGII 도로중심선 `lt_l_n3a0020000`
- 정밀 요소: 도로면 하위에서 체크한 차도·노면표시·신호·안전시설만 WFS 수집
- 실물 컨텍스트: VWorld 실물 3D의 교량·고가도로

정밀 요소는 기본 사이트 분석을 느리게 하지 않습니다. 한 번 켠 항목은
`out/<대상지>/cache/precision_roads/`에 저장하고 30일 동안 다시 씁니다. 도로면의
검증된 지역판은 `cache/roads/<dsId>/<지역>/versions/`에 계속 보존되며 `current.json`만
현재판을 가리킵니다. 2D 도로면의 **버전 확인**은 ZIP을 바꾸지 않고 공식 목록만 갱신합니다.
